The script also writes:

- `checksums_sha256_exhibits.txt` — SHA-256 of the source file and every clip (verify with `sha256sum -c checksums_sha256_exhibits.txt`).
- `clip_run_<timestamp>.txt` — run log: ffmpeg version, source hash, requested vs. actual clip boundaries.
- `ffprobe_<exhibit>.txt` — stream metadata for each clip for the foundation witness.

**Keyframe note for the foundation witness:** stream copy can only cut on a keyframe, so each clip may begin up to a few seconds *before* the requested clock time. It never starts late and never drops frames inside the window. The run log records the exact start offset used.
